STEP136 - Excel Logo Auto-Fit

Added dedicated Excel logo settings in Settings > Branding & Header:
- Select Excel logo slot (Logo 1 / 2 / 3)
- Excel logo width
- Excel logo height
- Excel cell padding
- Auto enlarge Excel logo cell

Behavior:
- Annual and Monthly Excel use only the selected Excel logo.
- The logo stays inside merged cell A1:C1.
- Row 1 height automatically increases with the Excel logo height so the logo does not cover KPI rows.
- Web header logo sizes remain independent from Excel logo size.
- "Apply Branding to Existing Excel Files" applies the Excel logo size to existing files.
