SMART PM - OPTIONAL REPORT ISSUE / COMMENT FEATURE

Added feature:
- A new "Report Issue" option appears beside the PM action.
- Reporting an issue is OPTIONAL.
- It does NOT mark the PM task as completed.
- Technician can report a problem/comment found during PM.
- The latest issue/comment is displayed in the PM task table with reporter and date/time.
- Multiple issue entries are retained in data/pm_issues.json for traceability.
- Current PM week: authorized users can report issues.
- Historical PM: Admin only.
- Future PM: read-only; issue reporting is disabled.
- Existing Done / Undo behavior is preserved.
