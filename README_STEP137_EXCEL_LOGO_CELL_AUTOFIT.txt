STEP137 - Excel logo cell auto-fit

Fix:
- Excel logo height now changes Row 1 height.
- Excel logo width now enlarges columns A:C when required, so merged cell A1:C1 grows with the logo.
- Excel logo limits increased to 700 x 350 px.
- Padding is included in both row height and merged-cell width calculations.
- Applies to new Annual/Monthly files and to existing files when using Branding > Apply Branding to Existing Excel Files.

Important:
After changing Excel logo settings, click Save Header Settings, then Apply Branding to Existing Excel Files for files already created.
